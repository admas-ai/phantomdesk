## Description prepared for the upload

Which instructions did the reviewer actually approve?

PhantomDesk is a browser-local maintenance review desk. Approval belongs to one saved revision. Changed instructions or a new duplicate-review condition break the seal, preserve the earlier decision, and require another review before export.

Try the working app: https://phantomdesk.neighborlyhydrangea16.chatgpt.site/
Public source (MIT): https://github.com/admas-ai/phantomdesk
Kiro development record: https://github.com/admas-ai/phantomdesk/blob/main/docs/KIRO-USAGE.md

This edited walkthrough uses actual browser captures and wholly synthetic maintenance requests. It shows missing-information blocking, approval, changed instructions, a rejected stale download, historical comparison, reapproval, and a later duplicate. The separate unsaved-draft check is labeled in the video.

Development attribution: Codex authored the original prototype. Kiro CLI implemented the approval-comparison helper, historical selector, comparison renderer and styles, and eight additional domain tests from the project brief. Independent Codex review corrected comparison details, stable selection, cross-tab draft behavior, and mobile labels. The final domain suite has 42 passing tests; nine real-browser IndexedDB checks also passed on November 28, 2026.

Built with HTML, CSS, JavaScript modules and IndexedDB. No runtime AI service is required. Records stay in the browser, and reviewer labels are not authenticated identities.

The narration uses an AI-generated voice. No customer adoption, revenue or measured operational savings are claimed.

Prepared as part of the Kiroween 2026 hackathon.
